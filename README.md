# 拳馆 AI 项目｜第七期教学源码

作者：林策在做了 · Lince。

这是为本期视频新做的隔离练习，不是当年客户的完整拳馆系统。所有会员、课程、订单和经营记录均为虚构数据。本包只在自己的电脑运行，不部署到公网。

## 先运行预约练习

需要 Python 3.10 或更新版本、浏览器。已在 macOS 的 Python 3.12 验证。无 pip、npm 或第三方库安装步骤。

1. 解压到一个新的文件夹，在终端进入这个文件夹。
2. 确认 `python3 --version` 显示 Python 3.10+；以下步骤仅在 macOS 实机验证；其他系统需要自行验证 Python 安装与启动方式。
3. 执行 `python3 app.py`。
4. 浏览器打开 `http://127.0.0.1:8767`。
5. 终端按 Ctrl+C 停止。下次执行同一命令会保留预约记录。

若端口占用，执行 `python3 app.py --port 8877`，浏览器地址也改成 8877。不停止其他程序。

初始状态：总课时3、预留0、已用0、可约3。预约→管理视图核对同一个编号→再提交一次→取消→刷新。重复提交不重复预留；取消后可约恢复为3，已用仍为0。角色切换只是教学视图，不能当正式权限系统。

## 重置与保存

页面点击“重置预约练习”并确认，或先停止服务再执行 `python3 app.py --reset`。只清理这个包 `data/booking.sqlite3` 中的预约，不删除报告回执。重新预约会生成新编号。

预约数据由服务端保存到本目录的 SQLite 文件。刷新和服务重启后保留。只支持单机、单服务教学场景；不承诺多进程生产部署。代码版本和数据库备份是两件事。

## 真实经营报告

先不配置密钥，也能查看和复算固定统计。实时生成需要自己的已授权 DeepSeek 服务账户及有效额度；本包不赠送额度、不包含密钥、不代充值。

macOS 已准备可直接执行的隐藏输入入口：先停止原服务，在本包目录执行 `python3 run_with_model.py`。终端会提示输入自己的 API Key；输入时不显示字符，按回车启动。密钥只放在本次进程的 `DEEPSEEK_API_KEY` 环境变量中，不写文件、不放命令参数或历史。停止按 Ctrl+C，下次启动需要重新提供。凭证输入这一步不录屏，也不把真实密钥粘贴到聊天。

若已有安全配置的 `DEEPSEEK_API_KEY`，该入口直接使用它。`.env.example` 仅说明变量名，不会自动加载，复制为 `.env` 也不会生效。可选设置 `EP07_MODEL`，本次验证的模型ID为 `deepseek-flash`；只向 `https://api.deepseek.com/chat/completions` 发送虚构汇总和问题。模型能力和费用以自己的账户为准。

在“经营报告”页输入问题后点击“实时调用模型生成报告”。点击前会确认一次调用；失败显示错误，不自动重试，也不自动切换为预制回答。问题最长300字，不输入真实客户资料。密钥只在服务端运行环境，不能放到页面或录屏里。

“读取本机上次真实回执”仅回放本机 `data/latest-report.json`，不会产生新请求。干净解压包没有历史回答；它不是离线成功示例。完整请求、摘要、返回和回执保存在 `data/reports/`；目录不应公开分享。

开发者可以配置 `EP07_MODEL_ADAPTER` 指向自己已有的、兼容本包调用参数的本机适配器。它是可选入口，不是观众必需条件，本包不提供任何私人适配器或绝对路径。默认直接 API 路线已经实测。

经营报告使用 `fixtures/report.json` 中另一组固定虚构记录，和刚才的预约练习分开；练习取消不会变成统计样本里的上课或收入。

期间：2026-09-01 00:00（含）至2026-09-08 00:00（不含），包含9月7日全天。

- 完成：S01、S02、S03、S04，共4次。
- 取消：S05、S06，共2次。S07在9月8日，排除。
- 活跃：M-A、M-B、M-C，共3人；登记4人，覆盖3/4=75%。这不是留存。

执行 `python3 -m unittest -v test_sample.py`。测试用临时目录，不改你的练习数据。另按 `docs/验收步骤.md` 检查浏览器实际结果。提示词、需求与记录方法见 `docs/`。

本包不包含登录、支付、核销功能、云部署、客户源码、真实会员数据、个人配置、运行数据库和已付费调用的完整日志。后续新增这些能力需要新的需求与验收，不能将教学角色切换当身份验证。

依赖及分发说明见 `DEPENDENCIES.md`。包版本和文件哈希见 `PACKAGE-MANIFEST.json`。这是本期视频使用的教学版快照，代码与已验收小样一致。仓库包含源码、运行说明和虚构数据；不包含原客户系统或完整开发聊天记录。
