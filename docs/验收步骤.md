# 验收步骤

1. 启动后初始3/0/0/3。预约，记下BK编号；预留1、已用0、可约2、课程名额0。
2. 管理视图看到同一个BK编号。重复提交，记录数与预留不增加。
3. 取消，原记录变已取消；预留0、已用0、可约3、名额1。
4. 刷新。停止后重新启动，已取消记录仍在。重置后才清空。
5. 经营报告展开原始记录表：S01–S04完成，S05–S06取消，S07排除；收款O01+O02=1500，O03排除。
6. 配置自己的模型服务，输入问题并点击实时生成；核对本次request_id、起止时间和返回模型。无配置时应清楚失败，不能出现假报告。
7. 问利润与留存，应说明缺少成本和同批追踪，不输出虚构利润或提升幅度。模型文本仍需人工检查，不能把提示要求当保证。
8. 不配置密钥的干净包只能运行预约与确定性统计。历史回放无记录时明确为空；有记录时明确标“回放”。
